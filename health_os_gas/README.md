# Health OS на Google Apps Script

Версия бота «Здоровье семьи», которая работает на серверах Google — **круглосуточно, бесплатно, независимо от того, включён ли ваш MacBook**.

Это замена Python-версии (`health_os_bot/`), а не дополнение: одновременно работать может только одна из них.

## Два способа вносить данные

| | Через Telegram | Руками в таблице |
|---|---|---|
| Когда удобнее | одно-два значения на ходу, голосом, фото бланка | накопилась стопка бланков за год |
| Куда попадает | лист `Analyses` / `Medical_Data` | **те же самые листы** |
| Списки | бот подсказывает сам | выпадающие списки в ячейках |

Отдельных «входных» листов намеренно нет: чем меньше листов, тем понятнее выгрузка, если отдать таблицу целиком ChatGPT или Gemini.

## Как устроены листы

| Лист | Что это |
|---|---|
| `Анализы` | Строка = один человек на одну дату, колонки = показатели, как бумажный бланк |
| `Обследования` | УЗИ, ЭКГ, приёмы врачей, госпитализации |
| `Дневник` | Сон, питание, тренировки |
| `Справочник анализов` | Показатели: группа, название, единицы, код, нормы |
| `Справочник обследований` | Типы обследований для выпадающего списка |
| `Личные нормы` | Индивидуальные нормы (например, детские) — важнее всех остальных |
| `Мои правила` | «Если гемоглобин низкий, помогает гранат» |
| `Семья` | Кто, пол, год рождения. Колонка «Кто» подставляется во все списки |
| `Доступ` | Кто из семьи привязан к какому Telegram-аккаунту и с какой ролью |
| `Служебное` | На каком шаге диалога находится каждый чат |
| `Ошибки` | Появляется сам, если бот на чём-то споткнулся |

Названия листов, колонок и значений — по-русски. Таблицу заполняет человек,
и ему не должно требоваться переводить `family_member_id`. Код при этом
продолжает понимать старые английские значения пола и роли: в листах могли
остаться строки от прежней версии, а молча перепутать норму для мужчины и
женщины — худшее, что тут может случиться.

### Ввести анализы руками

1. Лист `Анализы`, новая строка: **Дата**, **Кто** (выпадающий список), дальше значения по колонкам.
2. Пустые колонки оставляйте пустыми — бот считает «последним известным» последнее непустое значение.
3. Меню **🩺 Health OS → Проверить анализы по нормам** прокрасит значения: красным — вне нормы, зелёным — в норме.

### Ввести анализы строкой в Telegram

Кнопки не обязательны. Достаточно написать боту:

```
Адель МНО 2,5 С-реактивный белок 2 15.07.2025
```

Разделители не нужны, порядок любой. Имя из семьи в любом месте строки — за кого записать (без имени бот спросит кнопкой либо запишет за вас, если доступен только один человек). Дата в любом виде: `15.07.2025`, `15.07.25`, `2025-07-15`, `вчера`. Без даты — сегодняшнее число.

Название, за которым стояло число, но которого нет в справочнике, бот назовёт отдельно: «не понял и не записал: пульс». Молча выбрасывать нельзя — иначе кажется, что запись сохранена целиком.

### Добавить свой показатель

1. Лист `Справочник анализов`, новая строка: группа, **показатель**, единицы, нормы, **синонимы**.
   Колонка «Код» заполнится сама.
2. Меню **🩺 Health OS → Обновить списки и колонки** — в `Анализы` появится новая колонка.
3. Бот сразу начнёт понимать и название, и любой синоним из этой строки.

Колонка «Синонимы» — сокращения из бланков лаборатории через запятую (`СРБ, CRP`). Благодаря ей новое сокращение не требует правки кода.

Нормы необязательны: для 19 базовых показателей они зашиты в `Norms.gs`. Заполняйте, если ваша лаборатория даёт другие референсы.

### Записать обследование

Лист `Обследования`: дата, кто, что это было (выпадающий список — своё вписать тоже можно), заключение, ссылка на скан. Столбец «Служебный id» заполняет бот.

### Особенности организма

Лист `Особенности`: кто, тип (аллергия, непереносимость, хроническое заболевание, ограничение по питанию, постоянное лекарство, перенесённая операция), описание.

В отличие от листа `Мои правила`, который срабатывает при отклонении показателя, это верно всегда. Бот показывает особенности в отчёте, и именно эти строки нужны ИИ, когда ему отдают базу целиком: без них он посоветует бананы человеку, которому нельзя калий.

Через Telegram — кнопка **🧬 Особенности**.

## Файлы кода

| Файл | Назначение |
|---|---|
| `Polling.gs` | **Мотор.** Раз в минуту забирает новые сообщения из Telegram |
| `Main.gs` | Все диалоги: дневник, анализы, обследования, правила, отчёт |
| `Telegram.gs` | Вызовы Telegram API, клавиатуры, разбор сообщений |
| `Sheets.gs` | Чтение/запись листов, права доступа, `Sessions` |
| `Norms.gs` | Нормы, справочник, личные нормы, разбор текста анализов |
| `Rules.gs` | Рекомендации по отклонениям + личные правила |
| `Media.gs` | Голос (Whisper API) и фото (GPT-4o) |
| `Entry.gs` | Меню таблицы, выпадающие списки, колонки, авто-код показателя |
| `Setup.gs` | Первичная настройка |
| `tests/test_logic.js` | Проверка логики (53 теста) |

## Развёртывание

### 1. Открыть редактор скриптов
В таблице «Здоровье семьи» → меню **Расширения → Apps Script**.

### 2. Перенести файлы

**Одной командой через clasp** (настроено, так и обновляем дальше):

```bash
cd health_os_gas && clasp push -f
```

Первый раз нужно: `npm i -g @google/clasp`, затем `clasp login`, включить переключатель
**Google Apps Script API** на https://script.google.com/home/usersettings и создать
`.clasp.json` с id скрипта из адресной строки редактора:

```json
{"scriptId": "id из адреса script.google.com/home/projects/<ЭТО>/edit", "rootDir": "."}
```

Файл `tests/` в Apps Script не уезжает — он исключён через `.claspignore`.
Это важно: тесты написаны для JXA и начинаются с `ObjC.import`, который сломал бы
загрузку всего проекта.

**Вручную** (если clasp недоступен): для каждого `.gs` файла слева **+ → Скрипт**,
назвать так же (без `.gs`), вставить содержимое. Копировать через `pbcopy` **нельзя**:
он читает файл как Mac Roman, и кириллица приезжает мусором, причём проверка через
`pbpaste` этого не показывает — она разворачивает искажение обратно. Если всё же
через терминал, то так:

```bash
__CF_USER_TEXT_ENCODING=0x1F5:0x8000100:0x8000100 pbcopy < Main.gs
```

### 3. Задать секреты
**⚙️ Настройки проекта → Свойства скрипта → Добавить свойство:**

| Свойство | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `OPENAI_API_KEY` | ключ OpenAI |
| `DRIVE_FOLDER_ID` | id папки Google Drive для фото (из её URL) |
| `BOOTSTRAP_ADMIN_IDS` | ваш Telegram id (нужен, только если таблица пустая) |

### 4. Создать лист Sessions
В редакторе выбрать функцию `setup` → **Выполнить**. Появится запрос прав — разрешить.

### 5. Включить бота
Выбрать функцию `startPolling` → **Выполнить**. Всё: бот проверяет новые сообщения раз в минуту.

Развёртывать веб-приложение **не нужно**. Webhook на Apps Script не работает: Google отвечает редиректом 302, Telegram считает доставку неудачной и присылает то же сообщение снова — однажды так пришло 30 приветствий подряд. Поэтому бот забирает сообщения сам, а функции `doPost` в коде нет: открытый на «у всех» веб-эндпоинт принимал бы и поддельные апдейты.

### 6. Выключить старого бота на Mac
Двойной клик по **«Остановить бота.command»** на Рабочем столе. Иначе два бота будут конфликтовать.

## Скорость: чего ожидать

Google не умеет запускать триггеры чаще раза в минуту, поэтому **первое** сообщение после паузы бот забирает в течение минуты. Дальше он остаётся на линии ещё 50 секунд и отвечает почти мгновенно — то есть внутри диалога кнопки не «залипают».

Так сделано из-за квоты: у обычного аккаунта Google на все триггеры отведено **90 минут работы в сутки**. Непрерывный опрос израсходовал бы их за полтора часа, и бот замолчал бы до следующего дня.

Если бот начнёт замолкать к вечеру — выполните `checkTriggerBudget()` и уменьшите `POLL_BURST_MS` в `Polling.gs` (50000 → например 20000). Если наоборот хочется быстрее и квоты хватает — увеличьте.

Справочные листы (семья, доступы, справочник, личные нормы) бот держит в памяти **6 часов**: без этого каждое нажатие кнопки открывало таблицу 5-7 раз. Правки в таблице подхватываются сразу — при ручном редактировании кэш нужного листа сбрасывается сам. Если что-то всё же разошлось: меню **🩺 Health OS → Сбросить кэш бота**.

Отдельно: отказ в доступе не кэшируется никогда. Человек, написавший боту раньше, чем его внесли в лист `Users`, заработает сразу после внесения, а не через 6 часов.

## Полезное

- **Выключить бота:** выполнить `stopPolling()`.
- **Бот тормозит:** `checkTriggerBudget()` покажет расход квоты за сутки.
- **Логи ошибок:** в редакторе слева — **Выполнения**.
- **Бот молчит:** выполнить `getWebhookInfo()`. Если там прописан адрес — `getUpdates` отвечает ошибкой 409; лечится `deleteWebhook()` (его же вызывает `startPolling`).
- **После правки кода** ничего переразвёртывать не нужно: триггер `poll` берёт актуальную версию.

```bash
cd health_os_gas && osascript -l JavaScript tests/test_logic.js
```
