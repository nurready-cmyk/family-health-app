# Health OS на Google Apps Script

Версия бота «Здоровье семьи», которая работает на серверах Google — **круглосуточно, бесплатно, независимо от того, включён ли ваш MacBook**.

Это замена Python-версии (`health_os_bot/`), а не дополнение: одновременно работать может только одна из них.

## Два способа вносить данные

| | Через Telegram | Руками в таблице |
|---|---|---|
| Когда удобнее | одно-два значения на ходу, голосом, фото бланка | накопилась стопка бланков за год |
| Куда попадает | лист `Analyses` / `Medical_Data` | **те же самые листы** |
| Списки | бот подсказывает сам | выпадающие списки в ячейках |

Отдельных «входных» листов намеренно нет: чем меньше листов, тем понятнее выгрузка, если отдать таблицу целиком ChatGPT или Gemini.

## Как устроены листы

| Лист | Что это |
|---|---|
| `Analyses` | Анализы. Строка = один человек на одну дату, колонки = показатели — как бумажный бланк |
| `Medical_Data` | Обследования: УЗИ, ЭКГ, приёмы врачей, госпитализации |
| `Справочник_Анализов` | Список показателей: группа, название, единицы, код, нормы |
| `Справочник_Обследований` | Список типов обследований для выпадающего списка |
| `Личные_Нормы` | Индивидуальные нормы (например, детские) — важнее всех остальных |
| `Family_Members` | Семья. `id` = имя, оно же подставляется в выпадающие списки |
| `Users` | Кто из семьи привязан к какому Telegram-аккаунту и с какой ролью |
| `Logs` | Дневник: сон, питание, тренировки |
| `Knowledge_Base` | Личные правила («если гемоглобин низкий, помогает гранат») |
| `Sessions` | Служебный: на каком шаге диалога находится каждый чат |

### Ввести анализы руками

1. Лист `Analyses`, новая строка: **Дата**, **Кто** (выпадающий список), дальше значения по колонкам.
2. Пустые колонки оставляйте пустыми — бот считает «последним известным» последнее непустое значение.
3. Меню **🩺 Health OS → Проверить анализы по нормам** прокрасит значения: красным — вне нормы, зелёным — в норме.

### Добавить свой показатель

1. Лист `Справочник_Анализов`, новая строка: группа, **русское название**, единицы, нормы.
   Код (`indicator_key`) проставится сам.
2. Меню **🩺 Health OS → Обновить списки и колонки** — в `Analyses` появится новая колонка.
3. Этот же показатель бот теперь понимает и в Telegram: «мочевина 5.4».

Нормы в справочнике необязательны: для 19 базовых показателей они зашиты в `Norms.gs`. Заполняйте, если ваша лаборатория даёт другие референсы.

### Записать обследование

Лист `Medical_Data`: дата, кто, тип (выпадающий список из `Справочник_Обследований` — своё вписать тоже можно), заключение, ссылка на скан. Столбец `id` служебный, руками не нужен.

## Файлы кода

| Файл | Назначение |
|---|---|
| `Polling.gs` | **Мотор.** Раз в минуту забирает новые сообщения из Telegram |
| `Main.gs` | Все диалоги: дневник, анализы, обследования, правила, отчёт |
| `Telegram.gs` | Вызовы Telegram API, клавиатуры, разбор сообщений |
| `Sheets.gs` | Чтение/запись листов, права доступа, `Sessions` |
| `Norms.gs` | Нормы, справочник, личные нормы, разбор текста анализов |
| `Rules.gs` | Рекомендации по отклонениям + личные правила |
| `Media.gs` | Голос (Whisper API) и фото (GPT-4o) |
| `Entry.gs` | Меню таблицы, выпадающие списки, колонки, авто-код показателя |
| `Setup.gs` | Первичная настройка |
| `tests/test_logic.js` | Проверка логики (47 тестов) |

## Развёртывание

### 1. Открыть редактор скриптов
В таблице «Здоровье семьи» → меню **Расширения → Apps Script**.

### 2. Перенести файлы
Для каждого `.gs` файла: слева **+ → Скрипт**, назвать так же (без `.gs`), вставить содержимое.
Файл `appsscript.json` виден после включения: **⚙️ Настройки проекта → «Показывать файл манифеста»**.

### 3. Задать секреты
**⚙️ Настройки проекта → Свойства скрипта → Добавить свойство:**

| Свойство | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `OPENAI_API_KEY` | ключ OpenAI |
| `DRIVE_FOLDER_ID` | id папки Google Drive для фото (из её URL) |
| `BOOTSTRAP_ADMIN_IDS` | ваш Telegram id (нужен, только если таблица пустая) |

### 4. Создать лист Sessions
В редакторе выбрать функцию `setup` → **Выполнить**. Появится запрос прав — разрешить.

### 5. Включить бота
Выбрать функцию `startPolling` → **Выполнить**. Всё: бот проверяет новые сообщения раз в минуту.

Развёртывать веб-приложение **не нужно**. Webhook на Apps Script не работает: Google отвечает редиректом 302, Telegram считает доставку неудачной и присылает то же сообщение снова — однажды так пришло 30 приветствий подряд. Поэтому бот забирает сообщения сам, а функции `doPost` в коде нет: открытый на «у всех» веб-эндпоинт принимал бы и поддельные апдейты.

### 6. Выключить старого бота на Mac
Двойной клик по **«Остановить бота.command»** на Рабочем столе. Иначе два бота будут конфликтовать.

## Полезное

- **Выключить бота:** выполнить `stopPolling()`.
- **Логи ошибок:** в редакторе слева — **Выполнения**.
- **Бот молчит:** выполнить `getWebhookInfo()`. Если там прописан адрес — `getUpdates` отвечает ошибкой 409; лечится `deleteWebhook()` (его же вызывает `startPolling`).
- **После правки кода** ничего переразвёртывать не нужно: триггер `poll` берёт актуальную версию.

## Тесты

```bash
cd health_os_gas && osascript -l JavaScript tests/test_logic.js
```

Проверяют разбор анализов, нормы (включая детские и свои показатели вроде МНО), даты, приведение дат из ячеек и генерацию кодов — без обращения к сети и таблице.
