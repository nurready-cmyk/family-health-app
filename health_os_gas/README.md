# Health OS на Google Apps Script

Версия бота «Здоровье семьи», которая работает на серверах Google — **круглосуточно, бесплатно, независимо от того, включён ли ваш MacBook**.

Это замена Python-версии (`health_os_bot/`), а не дополнение: одновременно работать может только одна из них.

## Что изменилось по сравнению с Python-версией

| | Python (на Mac) | Apps Script (на Google) |
|---|---|---|
| Работает, когда ноутбук выключен | ❌ | ✅ |
| Падает и лежит часами | ❌ бывало | ✅ невозможно |
| Google-таблица | та же самая | **та же самая** |
| Голосовые | faster-whisper (локально, бесплатно) | Whisper API (~$0.006/мин) |
| Фото, текст | GPT-4o / GPT-4o-mini | без изменений |
| Состояние диалога | терялось при перезапуске | хранится в листе `Sessions` |

**Данные не мигрируют** — это та же таблица, те же 8 листов. Меняется только «мотор».

## Файлы

| Файл | Назначение |
|---|---|
| `Main.gs` | Точка входа `doPost` + все диалоги (дневник, анализы, обследования, правила, отчёт) |
| `Telegram.gs` | Вызовы Telegram API, клавиатуры, разбор сообщений |
| `Sheets.gs` | Чтение/запись листов, права доступа, `Sessions` |
| `Norms.gs` | Нормы, справочник, личные нормы, разбор текста анализов |
| `Rules.gs` | Рекомендации по отклонениям + личные правила |
| `Media.gs` | Голос (Whisper API) и фото (GPT-4o) |
| `Setup.gs` | Первичная настройка и подключение webhook |
| `tests/test_logic.js` | Проверка логики (40 тестов) |

## Развёртывание

### 1. Открыть редактор скриптов
В таблице «Здоровье семьи» → меню **Расширения → Apps Script**.

### 2. Перенести файлы
Для каждого `.gs` файла: слева **+ → Скрипт**, назвать так же (без `.gs`), вставить содержимое.
Файл `appsscript.json` виден после включения: **⚙️ Настройки проекта → «Показывать файл манифеста»**.

### 3. Задать секреты
**⚙️ Настройки проекта → Свойства скрипта → Добавить свойство:**

| Свойство | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `OPENAI_API_KEY` | ключ OpenAI |
| `DRIVE_FOLDER_ID` | id папки Google Drive для фото (из её URL) |
| `BOOTSTRAP_ADMIN_IDS` | ваш Telegram id (нужен, только если таблица пустая) |

### 4. Создать лист Sessions
В редакторе выбрать функцию `setup` → **Выполнить**. Появится запрос прав — разрешить.

### 5. Развернуть веб-приложение
**Начать развёртывание → Новое развёртывание → тип «Веб-приложение»**:
- Запуск от имени: **я**
- У кого есть доступ: **у всех**

Скопировать выданный URL.

### 6. Подключить webhook
В `Setup.gs` вставить URL вместо `WEB_APP_URL_СЮДА`, сохранить, выполнить функцию `setWebhook`.

### 7. Выключить старого бота на Mac
Двойной клик по **«Остановить бота.command»** на Рабочем столе. Иначе два бота будут конфликтовать.

## Полезное

- **Проверить webhook:** выполнить `getWebhookInfo()`, посмотреть журнал.
- **Логи ошибок:** в редакторе слева — **Выполнения**.
- **Вернуться на Python-версию:** выполнить `deleteWebhook()`, затем запустить Mac-бота.
- **После правки кода:** обязательно **Развернуть → Управление развёртываниями → ✏️ → Версия: новая**, иначе Telegram будет работать со старым кодом.

## Тесты

```bash
osascript -l JavaScript tests/test_logic.js
```

Проверяют разбор анализов, нормы (включая детские и свои показатели вроде МНО), даты и генерацию id — без обращения к сети и таблице.
