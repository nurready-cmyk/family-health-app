# Health OS на Google Apps Script

Версия бота «Здоровье семьи», которая работает на серверах Google — **круглосуточно, бесплатно, независимо от того, включён ли ваш MacBook**.

Это замена Python-версии (`health_os_bot/`), а не дополнение: одновременно работать может только одна из них.

## Два способа вносить данные

| | Через Telegram | Руками в таблице |
|---|---|---|
| Когда удобнее | одно-два значения на ходу, голосом, фото бланка | накопилась стопка бланков за год |
| Куда попадает | лист `Analyses` / `Medical_Data` | **те же самые листы** |
| Списки | бот подсказывает сам | выпадающие списки в ячейках |

Отдельных «входных» листов намеренно нет: чем меньше листов, тем понятнее выгрузка, если отдать таблицу целиком ChatGPT или Gemini.

## Как устроены листы

| Лист | Что это |
|---|---|
| `Как читать эту базу` | Первый лист. Шпаргалка для ИИ и для человека |
| `Анализы` | Строка = один результат одного показателя. Один визит с 15 показателями — 15 строк с одной датой и именем |
| `Обследования` | УЗИ, ЭКГ, приёмы врачей, госпитализации |
| `Справочник анализов` | Показатели: группа, название, единицы, код, нормы, синонимы |
| `Справочник обследований` | Типы обследований для выпадающего списка |
| `Личные нормы` | Индивидуальные нормы (например, детские) — важнее общих |
| `Особенности` | Аллергии, непереносимости, хронические болезни — верно всегда |
| `Семья` | Кто, пол, год рождения |
| `Доступ` | Кто из семьи привязан к какому Telegram-аккаунту и с какой ролью |
| `Служебное` | На каком шаге диалога находится каждый чат |
| `Ошибки` | Появляется сам, если бот на чём-то споткнулся |

Названия листов, колонок и значений — по-русски. Код продолжает понимать
старые английские значения пола и роли — молча перепутать норму для мужчины
и женщины худшее, что тут может случиться.

Дневник (сон/питание/тренировки), «Моё правило» и «Лекарства» убраны из
бота по решению пользователя — таблица была перегружена, а эти листы стояли
пустыми. Вместе с дневником ушёл и голосовой ввод: он был единственным
местом, куда писала расшифровка голоса.

### Почему «Анализы» — длинный список, а не бланк

Раньше лист был широким: строка на дату, колонка на каждый показатель. Это
удобно заполнять, но с ростом числа показателей столбцов становится 40+, и
каждый новый анализ — это новый столбец правее. Длинный формат устраняет обе
проблемы: колонок всегда девять, а показатель выбирается из выпадающего
списка, который сам подтягивает справочник.

### Ввести анализы руками

Всегда заполняйте **строку 2** — сразу под шапкой. Как только в ней
заполнены Дата, Кто, Показатель и Значение, она сама уезжает вниз, а
наверху появляется новая пустая строка 2. Прокручивать лист вниз никогда
не нужно, даже когда в нём тысячи строк за годы — самая свежая запись
всегда наверху, а следующая пустая строка ждёт там же.

То же самое для листа `Обследования`.

1. Строка 2: **Дата**, **Кто** (список), **Показатель**
   (список — сначала впишите его в `Справочник анализов`, если его там нет).
2. Единицы и код подставятся сами.
3. **Значение** — число. Необязательно: **Норма мин/макс (с бланка)**, если
   на бланке лаборатории напечатана своя норма — она точнее общего справочника.
4. Меню **🩺 Health OS → Проверить анализы по нормам** прокрасит колонку
   «Значение»: красным — вне нормы, зелёным — в норме.

Порядок приоритета норм: норма с бланка → личные нормы (дети) → справочник →
общая норма из кода.

### Ввести анализы строкой в Telegram

Кнопки не обязательны. Достаточно написать боту:

```
Адель МНО 2,5 С-реактивный белок 2 15.07.2025
```

Разделители не нужны, порядок любой. Имя из семьи в любом месте строки — за
кого записать. Дата в любом виде: `15.07.2025`, `15.07.25`, `2025-07-15`,
`вчера`. Без даты — сегодняшнее число.

Название, за которым стояло число, но которого нет в справочнике, бот
назовёт отдельно: «не понял и не записал: пульс».

### Отчёт по кнопкам

**📈 Отчёт** теперь не сваливает всё разом. Шаги: человек → **как
показать** (по группе / один показатель / всё сразу).

- **По группе** — Общий анализ крови, Биохимия, Свёртываемость... Внутри
  группы либо конкретный показатель, либо «Вся группа целиком» (последние
  значения по всем показателям группы).
- **Один показатель** — плоский список всех показателей человека, без
  привязки к группе — если сразу знаете, что ищете (например МНО).
- **Всё сразу** — старое поведение, полный список последних значений.

Списки (группы, показатели внутри группы, плоский список «Один показатель»)
отсортированы по алфавиту.

Оба пути «показатель» (через группу или напрямую) заканчиваются одинаково:
сколько последних результатов показать — 1, 2, 3, 5 или все.

На шаге выбора показателя не обязательно листать список — можно просто
написать название («МНО»), даже в падеже («ферритина»). Пригодится, когда
показателей станет много и список перестанет умещаться на экране.

Список групп и показателей у каждого человека свой — показываются только
те, по которым уже есть хоть одна запись.

### Спросить историю

Не нужно заходить в таблицу — история читается прямо в Telegram:

```
МНО за год
гемоглобин
узи за полгода
обследования за 3 месяца
```

Период необязателен — без него бот покажет всю историю. Понимает «за год»,
«за 6 месяцев», «за неделю», «за 30 дней», «за последний год», «за полгода».
Имя в начале строки — если в семье больше одного человека и оно не указано,
бот ответом не занимается (лучше «не понял», чем угадать не того).

Падежи не мешают: «результат ферритина Салима», «что с гемоглобином» — для
названий от 5 букв бот сам отбрасывает типичное русское окончание. Короткие
аббревиатуры (МНО, АСТ, АЛТ, ТТГ) находятся только точным словом — иначе
«мно» как начало слова совпало бы с «много».

Ответ — список «дата — значение», от старых к новым, с пометкой отклонения
от нормы. Для обследований — конкретный вид («узи щитовидной железы за
год»), вся группа («узи за год») или всё подряд («обследования за год»).

Показывает то же, что и запись: название должно стоять по смыслу рядом с
периодом или само по себе, а не быть случайным упоминанием где-то в длинном
вопросе — иначе «дай мне справку, где упоминается МНО, для страховой»
считалось бы запросом истории МНО, хотя человек спрашивал о другом.

### Добавить свой показатель

1. Лист `Справочник анализов`, новая строка: группа, **показатель**, единицы,
   нормы, **синонимы**. Код заполнится сам.
2. Показатель сразу появляется в выпадающем списке листа `Анализы` и в
   Telegram — можно писать и полное название, и любой синоним.

### Записать обследование

Лист `Обследования`: дата, кто, что это было (список — своё вписать тоже
можно), заключение, ссылка на скан. Новая запись тоже появляется в строке 2 —
см. «Ввести анализы руками» выше.

### Особенности организма

Лист `Особенности`: кто, тип (аллергия, непереносимость, хроническое
заболевание, ограничение по питанию, постоянное лекарство, перенесённая
операция), описание. Через Telegram — кнопка **🧬 Особенности**.

## Выгрузка в ChatGPT / Gemini / Claude

11 листов не путают ИИ — путают неясные заголовки, разрозненные ключи и
числа без контекста. Здесь у каждого листа осмысленное русское имя, у всех
данных общий ключ «Кто», а «Справочник анализов» даёт единицы и нормы прямо
рядом с показателем. Это по сути реляционная база, а не свалка таблиц —
такую структуру модели читают лучше, чем один большой лист.

`Файл → Скачать → Microsoft Excel (.xlsx)` и отдать файл целиком. Первый
лист, «Как читать эту базу», объясняет модели связи между остальными раньше,
чем она увидит сами данные — писать это в каждом запросе не нужно.

## Файлы кода

| Файл | Назначение |
|---|---|
| `Polling.gs` | **Мотор.** Раз в минуту забирает новые сообщения из Telegram |
| `Main.gs` | Все диалоги: анализы, обследования, особенности, отчёт |
| `Telegram.gs` | Вызовы Telegram API, клавиатуры, разбор сообщений |
| `Sheets.gs` | Чтение/запись листов, права доступа, `Sessions` |
| `Norms.gs` | Нормы, справочник, личные нормы, разбор текста анализов |
| `Rules.gs` | Рекомендации по отклонениям + личные правила |
| `Media.gs` | Голос (Whisper API) и фото (GPT-4o) |
| `Entry.gs` | Меню таблицы, выпадающие списки, колонки, авто-код показателя |
| `Setup.gs` | Первичная настройка |
| `tests/test_logic.js` | Проверка логики (116 тестов) |

## Развёртывание

### 1. Открыть редактор скриптов
В таблице «Здоровье семьи» → меню **Расширения → Apps Script**.

### 2. Перенести файлы

**Одной командой через clasp** (настроено, так и обновляем дальше):

```bash
cd health_os_gas && clasp push -f
```

Первый раз нужно: `npm i -g @google/clasp`, затем `clasp login`, включить переключатель
**Google Apps Script API** на https://script.google.com/home/usersettings и создать
`.clasp.json` с id скрипта из адресной строки редактора:

```json
{"scriptId": "id из адреса script.google.com/home/projects/<ЭТО>/edit", "rootDir": "."}
```

Файл `tests/` в Apps Script не уезжает — он исключён через `.claspignore`.
Это важно: тесты написаны для JXA и начинаются с `ObjC.import`, который сломал бы
загрузку всего проекта.

**Вручную** (если clasp недоступен): для каждого `.gs` файла слева **+ → Скрипт**,
назвать так же (без `.gs`), вставить содержимое. Копировать через `pbcopy` **нельзя**:
он читает файл как Mac Roman, и кириллица приезжает мусором, причём проверка через
`pbpaste` этого не показывает — она разворачивает искажение обратно. Если всё же
через терминал, то так:

```bash
__CF_USER_TEXT_ENCODING=0x1F5:0x8000100:0x8000100 pbcopy < Main.gs
```

### 3. Задать секреты
**⚙️ Настройки проекта → Свойства скрипта → Добавить свойство:**

| Свойство | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `OPENAI_API_KEY` | ключ OpenAI |
| `DRIVE_FOLDER_ID` | id папки Google Drive для фото (из её URL) |
| `BOOTSTRAP_ADMIN_IDS` | ваш Telegram id (нужен, только если таблица пустая) |

### 4. Создать лист Sessions
В редакторе выбрать функцию `setup` → **Выполнить**. Появится запрос прав — разрешить.

### 5. Включить бота
Выбрать функцию `startPolling` → **Выполнить**. Всё: бот проверяет новые сообщения раз в минуту.

Развёртывать веб-приложение **не нужно**. Webhook на Apps Script не работает: Google отвечает редиректом 302, Telegram считает доставку неудачной и присылает то же сообщение снова — однажды так пришло 30 приветствий подряд. Поэтому бот забирает сообщения сам, а функции `doPost` в коде нет: открытый на «у всех» веб-эндпоинт принимал бы и поддельные апдейты.

### 6. Выключить старого бота на Mac
Двойной клик по **«Остановить бота.command»** на Рабочем столе. Иначе два бота будут конфликтовать.

## Скорость: чего ожидать

Google не умеет запускать триггеры чаще раза в минуту, поэтому **первое** сообщение после паузы бот забирает в течение минуты. Дальше он остаётся на линии ещё 50 секунд и отвечает почти мгновенно — то есть внутри диалога кнопки не «залипают».

Так сделано из-за квоты: у обычного аккаунта Google на все триггеры отведено **90 минут работы в сутки**. Непрерывный опрос израсходовал бы их за полтора часа, и бот замолчал бы до следующего дня.

Если бот начнёт замолкать к вечеру — выполните `checkTriggerBudget()` и уменьшите `POLL_BURST_MS` в `Polling.gs` (50000 → например 20000). Если наоборот хочется быстрее и квоты хватает — увеличьте.

Справочные листы (семья, доступы, справочник, личные нормы) бот держит в памяти **6 часов**: без этого каждое нажатие кнопки открывало таблицу 5-7 раз. Правки в таблице подхватываются сразу — при ручном редактировании кэш нужного листа сбрасывается сам. Если что-то всё же разошлось: меню **🩺 Health OS → Сбросить кэш бота**.

Отдельно: отказ в доступе не кэшируется никогда. Человек, написавший боту раньше, чем его внесли в лист `Users`, заработает сразу после внесения, а не через 6 часов.

## Полезное

- **Выключить бота:** выполнить `stopPolling()`.
- **Бот тормозит:** `checkTriggerBudget()` покажет расход квоты за сутки.
- **Логи ошибок:** в редакторе слева — **Выполнения**.
- **Бот молчит:** выполнить `getWebhookInfo()`. Если там прописан адрес — `getUpdates` отвечает ошибкой 409; лечится `deleteWebhook()` (его же вызывает `startPolling`).
- **После правки кода** ничего переразвёртывать не нужно: триггер `poll` берёт актуальную версию.

## Тесты

```bash
cd health_os_gas && osascript -l JavaScript tests/test_logic.js
```

Проверяют разбор анализов, нормы (включая детские, свои показатели и норму с бланка лаборатории), даты, приведение дат из ячеек и генерацию кодов — без обращения к сети и таблице.
