# Health OS — как это выглядит и куда всё записывается

Этот документ — практический ответ на два вопроса: «что увидит семья в Telegram» и «где физически лежат данные». Архитектура и решения — в [PRD.md](PRD.md), здесь только эксплуатация.

## Команды бота (шпаргалка)

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | Первый вход; для вас как первого admin — регистрация |
| `/add_family_member` | только admin | Добавить жену/детей (с Telegram или без) |
| `/log` | все | Внести метрику: энергия/сон/питание/тренировка |
| *(голосовое сообщение)* | все | То же самое, но без кнопок — просто наговорить |
| *(фото)* | все | Отправить скан анализа — саммари + сохранение в Drive |
| `/analysis` | все | Внести показатели анализов текстом + сразу увидеть рекомендации |
| `/report` | все | Посмотреть **текущие** отклонения и рекомендации без нового ввода |
| `/add_rule` | все | Научить бота личному правилу («мне лично помогает...») |

---

## 1. Как выглядит сервис для пользователя

Всё происходит в одном Telegram-чате с ботом. Никакого сайта, приложения или пароля — только переписка.

### Первый запуск (только один раз, для вас как администратора)

```
Вы:   /start
Бот:  👋 Вы первый администратор Health OS. Как вас зовут?
Вы:   Нурлан
Бот:  Укажите пол:           [Мужской] [Женский]
Вы:   *нажимаете «Мужской»*
Бот:  Год рождения (например 1990)?
Вы:   1990
Бот:  Готово! Вы зарегистрированы как администратор.
      /add_family_member — добавить остальных членов семьи
      /log — внести данные о здоровье
```

### Добавление жены и детей (`/add_family_member`, только вы как admin)

```
Вы:   /add_family_member
Бот:  Как зовут нового члена семьи?
Вы:   Айгерим
Бот:  Укажите пол:           [Мужской] [Женский]
Вы:   *нажимаете «Женский»*
Бот:  Год рождения?
Вы:   1992
Бот:  Есть ли у него/неё свой Telegram? Если да — пришлите числовой Telegram ID.
      Если нет — отправьте «нет».
Вы:   987654321   (или «нет», если хотите вносить данные за неё сами)
Бот:  ✅ Добавлен новый член семьи: Айгерим
```

Если у жены есть свой Telegram — она дальше пишет боту **сама**, со своего телефона, и видит только свои данные (написать `/add_family_member` она не может — это только для admin).

Повторите для сына, дочки и т.д. — участников не ограничено.

### Ежедневный ввод метрик (`/log`)

```
Вы:   /log
Бот:  За кого вносим данные?      [Нурлан] [Айгерим] [Сын]
Вы:   *выбираете*
Бот:  Какая метрика?      [⚡ Энергия] [😴 Сон] [🍽️ Питание] [🏋️ Тренировка]
Вы:   *выбираете «⚡ Энергия»*
Бот:  ⚡ Энергия — введите значение:
Вы:   8
Бот:  Заметка (или отправьте «-», если нет):
Вы:   -
Бот:  ✅ Записано!
```

Если пишет сама жена (не admin) — шаг выбора «за кого» пропускается, она сразу попадает к выбору метрики.

### Голосовое сообщение — то же самое, но без кнопок

Вы просто наговариваете: *«сегодня энергия на восьмёрку, спал хорошо»* — бот сам:
1. Распознаёт речь **локально** (faster-whisper, бесплатно, без интернета);
2. Просит GPT-4o-mini превратить это в `{"metric_type": "energy", "value": "8"}`;
3. Показывает карточку:

```
Бот:  🎙️ Услышал: «сегодня энергия на восьмёрку, спал хорошо»

      📋 Понял: ⚡ Энергия = 8

      Сохранить?          [✅ Да, сохранить] [✏️ Исправить]
```

**Ничего не сохраняется, пока вы не нажмёте «Да»** — если распознавание ошиблось, жмёте «Исправить» и вводите вручную через `/log`.

### Фото анализа (просто отправьте фото боту)

```
Бот:  📸 Обрабатываю фото...
      *(через пару секунд редактирует то же сообщение)*
Бот:  📋 Понял: Общий анализ крови

      Гемоглобин снижен (110 г/л), остальные показатели в норме.

      📎 Скан: https://drive.google.com/file/d/.../view

      Сохранить?          [✅ Да, сохранить] [✏️ Исправить]
```

Оригинал фото сохраняется в Google Drive (ссылка кликабельна), саммари делает GPT-4o.

### Ввод показателей анализа текстом (`/analysis`) — сразу с рекомендациями

```
Вы:   /analysis
Бот:  За кого вносим анализы?      [Нурлан] [Айгерим]
Вы:   *выбираете*
Бот:  📊 Напишите показатели через запятую или каждый на новой строке.
      Например: гемоглобин 135, глюкоза 5.2, давление 120/80
Вы:   гемоглобин 100
Бот:  📊 Записал:
      • Гемоглобин: 100.0 г/л — ⬇️ ниже нормы

      💡 Рекомендации:
      🩸 Низкий гемоглобин
      Гемоглобин ниже нормы — возможна анемия
      Есть: Говядина, телятина (2-3 раза в неделю), Гречка, чечевица, шпинат...
      Исключить: Чай и кофе сразу после еды (блокируют железо)...
      Спорт: Умеренное кардио (ходьба 30 мин)...
```

### Посмотреть текущие отклонения и рекомендации без нового ввода (`/report`)

Показывает то же самое, что и `/analysis`, но по **последним уже сохранённым** показателям — не нужно ничего вводить заново, чтобы просто посмотреть текущую картину:

```
Вы:   /report
Бот:  За кого посмотреть отчёт?      [Нурлан] [Айгерим]
Вы:   *выбираете*
Бот:  📋 Текущие показатели:
      • Гемоглобин: 100.0 г/л — ⬇️ ниже нормы

      🧠 Из ваших личных заметок:
      • если гемоглобин низкий, у меня лично помогает только гранат

      💡 Рекомендации:
      🩸 Низкий гемоглобин ...
```

Если анализов ещё не было — бот так и скажет: «Нет сохранённых анализов. Введите через /analysis».

### Обучение бота личным правилам (`/add_rule`)

Если у вас/жены есть личный опыт («мне лично при низком гемоглобине помогает не общая рекомендация, а гранат») — бот запомнит это и в следующий раз покажет **вашу** заметку раньше общей рекомендации:

```
Вы:   /add_rule
Бот:  🧠 Опишите личное правило свободным текстом, например:
      если гемоглобин низкий, мне лично помогает больше гречки и меньше кофе
Вы:   если гемоглобин низкий, у меня лично помогает только гранат
Бот:  🧠 Запомнил! Буду учитывать это при отклонениях в анализах.
```

При следующем вводе анализа с тем же отклонением:

```
Бот:  📊 Записал: ...

      🧠 Из ваших личных заметок:
      • если гемоглобин низкий, у меня лично помогает только гранат

      💡 Рекомендации:
      🩸 Низкий гемоглобин ...
```

## 2. Куда физически записываются данные

**Всё** хранится в одной Google Таблице (Google Sheets) на вашем собственном Google-аккаунте — не на серверах разработчика, не у третьих лиц. Таблица — это и есть база данных. 6 листов (вкладок внизу таблицы):

| Лист | Что там | Пример строки |
|---|---|---|
| **Family_Members** | Все члены семьи, включая тех, у кого нет Telegram | `fm2, Айгерим, female, 1992` |
| **Users** | Только те, у кого есть Telegram-аккаунт + их роль | `u2, 987654321, Айгерим, user, fm2` |
| **Logs** | Ежедневные метрики (`/log`, голос) | `l5, 2026-07-11, fm2, energy, 8, ""` |
| **Medical_Data** | Анализы и обследования с фото (саммари + ссылка на скан) | `md1, 2026-07-11, fm2, "Общий анализ крови", "Гемоглобин снижен...", https://drive.google.com/...` |
| **Analyses** | Показатели анализов по отдельности (`/analysis`) — на них работают рекомендации | `a3, fm2, 2026-07-11, hemoglobin, 100` |
| **Knowledge_Base** | Личные правила (`/add_rule`) | `kb1, fm2, "если гемоглобин низкий, помогает гранат", 0` |

Сканы фото анализов (оригиналы, не саммари) лежат отдельно — в **папке Google Drive**, которую вы укажете при настройке. Ссылка на конкретный файл сохраняется в колонке `document_url` листа `Medical_Data`.

Ничего не уходит на сторонние серверы, кроме:
- Telegram (сама доставка сообщений — иначе никак);
- OpenAI (только текст транскрипта голоса или фото анализа — на несколько секунд, для структурирования, не для хранения).

## 3. Полная инструкция по разворачиванию

### Что понадобится
- Python 3.10 или новее
- Обычный Google-аккаунт (Gmail)
- Телефон с Telegram

### Шаг 1 — Создать бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather).
2. `/newbot` → введите имя и username (должен заканчиваться на `bot`).
3. Сохраните токен вида `123456789:AA...` — это `BOT_TOKEN`.

### Шаг 2 — Узнать свой Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot) и нажмите Start.
2. Он пришлёт ваш числовой ID — это `BOOTSTRAP_ADMIN_IDS` (именно с этим ID вы сможете зарегистрироваться как первый администратор через `/start`).

### Шаг 3 — Создать сервис-аккаунт Google

1. Откройте [console.cloud.google.com](https://console.cloud.google.com) → создайте новый проект (любое имя, например «Health OS»).
2. В меню слева: **APIs & Services → Library** → включите **Google Sheets API** и **Google Drive API** (искать по названию, кнопка Enable на каждом).
3. **APIs & Services → Credentials → Create Credentials → Service Account** → любое имя → Create and Continue → Done.
4. Откройте созданный сервис-аккаунт → вкладка **Keys** → **Add Key → Create new key → JSON** → скачается файл — переименуйте его в `credentials.json` и положите в папку `health_os_bot/`.
5. Скопируйте email сервис-аккаунта (выглядит как `health-os@ваш-проект.iam.gserviceaccount.com`) — понадобится в следующих двух шагах.

### Шаг 4 — Создать Google Таблицу

1. Создайте новую пустую таблицу на [sheets.google.com](https://sheets.google.com).
2. Нажмите **Настройки доступа** → вставьте email сервис-аккаунта из шага 3 → права **Редактор**.
3. Скопируйте ID таблицы из адресной строки: `https://docs.google.com/spreadsheets/d/ЭТОТ_ID_ЗДЕСЬ/edit` — это `GOOGLE_SHEET_ID`.

### Шаг 5 — Создать папку в Google Drive для сканов

1. Создайте новую папку на [drive.google.com](https://drive.google.com), например «Health OS — сканы».
2. Поделитесь ею с тем же email сервис-аккаунта, права **Редактор**.
3. Откройте папку, скопируйте её ID из адресной строки: `https://drive.google.com/drive/folders/ЭТОТ_ID_ЗДЕСЬ` — это `GOOGLE_DRIVE_FOLDER_ID`.

### Шаг 6 — Получить ключ OpenAI

1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com), привяжите способ оплаты (расходы минимальны — доли цента за сообщение).
2. **API keys → Create new secret key** → скопируйте — это `OPENAI_API_KEY`.

### Шаг 7 — Установить окружение

```bash
cd health_os_bot
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Шаг 8 — Заполнить `.env`

```bash
cp .env.example .env
```

Откройте `.env` и впишите значения, собранные на шагах 1–6:

```
BOT_TOKEN=123456789:AA...
OPENAI_API_KEY=sk-...
GOOGLE_SHEET_ID=...
GOOGLE_CREDENTIALS_PATH=credentials.json
GOOGLE_DRIVE_FOLDER_ID=...
WHISPER_MODEL_SIZE=base
BOOTSTRAP_ADMIN_IDS=ваш_telegram_id
```

### Шаг 9 — Создать листы в таблице

```bash
python -m database.setup
```

Должно вывести: `Готово: листы Family_Members, Users, Logs, Medical_Data, Knowledge_Base, Analyses созданы...` — откройте таблицу и убедитесь, что появились 6 вкладок с заголовками.

### Шаг 10 — Запустить бота

```bash
python bot.py
```

Первый запуск скачает модель `faster-whisper` (нужен интернет, разово, ~150 МБ для модели `base`) — дальше работает офлайн. В консоли должно появиться `Health OS bot is starting...`.

### Шаг 11 — Первое сообщение

Откройте вашего бота в Telegram → `/start` → пройдите регистрацию администратора (см. раздел 1) → готово, можно добавлять семью и пользоваться.

### Чтобы бот работал круглосуточно (не только пока открыт терминал)

Локальный запуск (`python bot.py`) подходит для проверки. Для реального постоянного использования нужен любой недорогой/бесплатный сервер (например, бесплатный tier на Oracle Cloud, или VPS за пару долларов в месяц) — процесс `bot.py` должен работать непрерывно. Это отдельный шаг, спросите отдельно, если нужна помощь с конкретным хостингом.
