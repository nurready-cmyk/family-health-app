# Telegram-бот «Здоровье семьи»

Бесплатный бот на Google Apps Script + Google Sheets. Никаких платных API, подписок или отдельных серверов — только бесплатный аккаунт Google и бесплатный Telegram Bot API.

## Что внутри

| Файл | Назначение |
|---|---|
| `Code.gs` | `doPost`-роутер, все диалоговые сценарии бота |
| `Telegram.gs` | Обёртка над Telegram Bot API (без сторонних библиотек) |
| `Sheets.gs` | Слой доступа к Google Sheets (профили, анализы, тренировки и т.д.) |
| `Norms.gs`, `Rules.gs`, `NutritionDB.gs` | Перенесённая база знаний из PWA (`js/norms.js`, `js/rules.js`, `js/nutrition-db.js`) |
| `Triggers.gs` | Ежедневный чек-ин (20:00) и еженедельный отчёт (воскресенье) |
| `Migration.gs` | Приём данных из PWA (кнопка в `profiles.html`) |
| `Setup.gs` | Одноразовая настройка листов и профилей |

## Шаг 1 — создать бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. `/newbot` → укажите имя и username (должен заканчиваться на `bot`).
3. Сохраните выданный токен вида `123456789:AA...` — понадобится в шаге 4.

## Шаг 2 — установить clasp и создать проект

Нужен Node.js ([nodejs.org](https://nodejs.org)). Если он уже стоит:

```bash
npm install -g @google/clasp
clasp login          # откроется браузер — войдите тем же Google-аккаунтом, где будет жить таблица
cd telegram-bot
clasp create --type sheets --title "HealthApp — Здоровье семьи"
```

`--type sheets` создаёт новую Google Таблицу и сразу привязывает к ней Apps Script — это то, что нужно `SpreadsheetApp.getActiveSpreadsheet()` в коде.

Если не хочется ставить Node.js: зайдите на [script.google.com](https://script.google.com), создайте новый проект, откройте связанную Таблицу (Ресурсы → но проще: создайте Таблицу вручную и в ней Расширения → Apps Script), и вручную скопируйте содержимое каждого `.gs`-файла из этой папки в одноимённый файл в редакторе.

## Шаг 3 — залить код

```bash
clasp push
```

## Шаг 4 — задать секреты

В редакторе Apps Script (`clasp open`): **Настройки проекта (⚙️) → Свойства скрипта → Добавить свойство скрипта**:

- `TELEGRAM_BOT_TOKEN` = токен из шага 1

`MIGRATION_SECRET` сгенерируется автоматически на шаге 5 — можно не создавать вручную.

## Шаг 5 — запустить setup()

В редакторе выберите функцию `setup` в выпадающем списке (наверху) → ▶ Выполнить. Разрешите запрошенные права доступа (это ваш собственный скрипт, работающий от вашего имени).

Это создаст все листы (`Profiles`, `Analyses`, `Workouts`, `Nutrition`, `Goals`, `Checkins`, `PersonalRules`, `Sessions`, `Config`) и 4 профиля: Я / Жена / Сын / Дочь. Откройте таблицу и поправьте имена/год рождения в листе `Profiles`, если нужно.

Посмотрите **Просмотр → Журналы** (или `Ctrl+Enter`) — там будет напечатан сгенерированный `MIGRATION_SECRET`, он же продублируется в Свойствах скрипта.

## Шаг 6 — задеплоить как Web App

В редакторе: **Развернуть → Новое развёртывание** → тип «Веб-приложение»:
- Execute as: **Me**
- Who has access: **Anyone**

Скопируйте выданный URL (`https://script.google.com/macros/s/XXXXX/exec`).

## Шаг 7 — подключить webhook Telegram

```bash
curl "https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=<URL_ИЗ_ШАГА_6>"
```

Должно вернуть `{"ok":true,"result":true,...}`.

## Шаг 8 — включить триггеры

В редакторе выберите функцию `setupTriggers` → ▶ Выполнить. Это регистрирует ежедневный чек-ин (20:00) и еженедельный отчёт (воскресенье, 19:00). Часовой пояс берётся из `appsscript.json` (`Asia/Almaty` по умолчанию — поменяйте в `appsscript.json` и файле → Настройки проекта, если у вас другой часовой пояс, затем `clasp push`).

## Шаг 9 — проверить в Telegram

Напишите боту `/start`, переключите профиль, введите `гемоглобин 100` — должна прийти рекомендация. Добавьте личное правило через кнопку «🧠 Моё правило», затем повторите ввод показателя — личная рекомендация должна появиться первой.

## Шаг 10 — перенести старые данные из PWA (опционально)

1. Откройте `profiles.html` в браузере (там, где уже накоплены данные).
2. В карточке «📮 Перенос в Telegram-бота» вставьте URL из шага 6 и `MIGRATION_SECRET` из шага 5.
3. Нажмите «Отправить в Google Sheets» — появится тост с количеством перенесённых записей.

Дневник энергии (`health_energy_log_*`) в этот перенос не входит — в текущей версии бота нет отдельного листа под него; при необходимости можно добавить лист `EnergyLog` и функцию миграции по аналогии с остальными.

## Ограничения бесплатного плана Google

- Web App выполнение: до 6 минут за вызов — с запасом для семейного использования.
- `UrlFetchApp` (вызовы Telegram API): 20 000/день на бесплатном аккаунте — с огромным запасом.
- Google Sheets: до ~10 млн ячеек на файл — хватит на годы записей.

Всё в рамках бесплатных лимитов Google при семейном использовании (4 профиля, несколько записей в день).
